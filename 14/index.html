가락 수금가 + 운송비 = 원가 · 익산원협 정산금액 = 매출 · 자사 중매인 낙찰분 제외

사진·PDF·엑셀 파일을 끌어다 놓거나 눌러서 고르세요

가락 물건명세서, 익산원협 정산서(팩스 TIF·PDF), 출고시세표를 자동으로 읽어 정산합니다. 화면 캡처나 엑셀에서 복사한 표는 Ctrl+V로 바로 붙여넣으면 됩니다. 휴대폰에서는 이 칸을 눌러 사진을 찍거나 파일을 고르거나, 붙여넣기 칸을 길게 눌러 붙여넣으세요.

① 가락시장 송품 (수금가)

물류비 미포함 금액. 단 단위는 10단 = 1박스로 운송비를 계산합니다.

정산서에 낙찰 중매인 번호가 없으면 자사 낙찰분은 직접 체크합니다.

③ 기타 공제 · 비용

하역비 미정산, 쓰레기유발금처럼 손익에서 따로 빼야 할 금액. 정산서에 공제 내역이 있으면 자동으로 들어갑니다.

기간별 수익률

저장된 날짜를 모아 계산합니다. 일별 행을 누르면 그 날짜를 엽니다.

운송비 기준표 · 설정 — 출고시세표 기준 박스(망)당 운송비

품목명은 쉼표로 구분합니다. 이 표에 없는 품목은 빨간 알림이 뜨고, 입력한 운송비는 아래 '개별 지정'에 남습니다. 출고시세표 파일을 끌어다 놓으면 새 품목이 해당 종류에 자동으로 들어갑니다.

Claude API 키 (파일로 열었을 때만)

사진·PDF 자동 읽기와 AI 총평에 씁니다. console.anthropic.com 에서 발급합니다. 키를 저장한 뒤 「키를 넣은 HTML 파일 만들기」를 누르면, 키와 지금까지 자료가 들어간 파일이 만들어집니다. 그 파일은 어느 컴퓨터에서 열어도 바로 AI가 됩니다. 사용 요금은 이 키로 청구되니 회사 밖으로 보내지 마세요.
