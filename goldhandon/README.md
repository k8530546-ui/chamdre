# 금한돈 "금 적립하기" 1시간 자동 클릭 (안드로이드)

휴대폰 혼자서(PC 없이) 1시간마다 금한돈 앱을 열고 **금 적립하기** 버튼을 누릅니다.
방법이 두 가지 있습니다. **코딩이 처음이라면 방법 A(MacroDroid)** 를 추천합니다.

---

## 공통 준비 (꼭 해주세요)

1. **화면 잠금**: "없음" / "밀기" 가 가장 확실합니다.
   - **패턴 잠금을 유지하고 싶다면 방법 B(AutoX.js)** 를 쓰세요. 스크립트가 패턴을 직접 그립니다 (아래 "패턴 잠금 설정" 참고).
   - PIN/비밀번호 잠금은 지원하지 않습니다.
2. **배터리 최적화 제외**: 설정 → 애플리케이션 → (MacroDroid 또는 AutoX.js) → 배터리 → **"제한 없음"**
   - 갤럭시: 설정 → 배터리 → 백그라운드 사용 제한 → **"절전 예외 앱"** 에 추가
3. 가능하면 **충전기에 꽂아둔 상태**로 두세요.

---

## 방법 A. MacroDroid (코딩 없이, 추천)

Play 스토어에서 **MacroDroid** 설치 (무료 버전으로 충분).

**매크로 추가** 를 누르고 아래처럼 설정합니다.

### 트리거
- **날짜/시간 → 정기 간격(Regular Interval)** → **1시간**

### 동작 (실제로 동작 확인한 순서)
갤럭시 폴드 가로 화면(해상도 2448×1848) 기준입니다. 금한돈은 웹 화면이라 글자 클릭이 안 돼서 **좌표(X,Y) 클릭**을 씁니다.

| # | 동작 | 설정 |
|---|------|------|
| 1 | 화면 → **화면 켜기** | |
| 2 | 애플리케이션 → **애플리케이션 실행** | 금한돈 |
| 3 | 매크로 → **다음 동작 전 대기** | 15초 |
| 4 | 기기 관련 동작 → **UI 자동조작** → 클릭 → **X,Y 위치** | 노란 "금 적립하기" 버튼 좌표 |
| 5 | **대기** | 40초 (광고 끝날 때까지, 부족하면 50~60초) |
| 6 | **UI 자동조작** → 클릭 → X,Y 위치 | X `1769`, Y `100` (광고 오른쪽 위 **»** 건너뛰기) |
| 7 | **대기** | 3초 |
| 8 | **UI 자동조작** → 클릭 → X,Y 위치 | X `1769`, Y `100` (같은 자리 **✕** 닫기) |
| 9 | **대기** | 2초 |
| 10 | **홈 화면 실행** | |

- 좌표 재는 법: 개발자 옵션 → **포인터 위치** 켜고 버튼을 누르면 화면 맨 위에 X, Y가 나옵니다.
- 휴대폰 방향(가로/세로, 접힘/펼침)이 바뀌면 좌표가 달라집니다.
- X,Y 설정 창의 **"터치 위치 표시"**를 켜면 어디를 눌렀는지 보여서 조정하기 쉽습니다.

- "UI 상호작용"을 처음 추가하면 **접근성 권한**을 켜라고 나옵니다 → 켜주세요.
- 매크로 저장 후 오른쪽 위 **▶ 테스트 실행**으로 한번 돌려보세요.

## 방법 B. AutoX.js 스크립트 (`auto_click.js`)

팝업 자동 닫기, 실패 시 로그 등 조금 더 똑똑하게 동작합니다.

1. **AutoX.js** 설치 (GitHub `kkevsekk1/AutoX` 의 Releases 에서 APK 다운로드)
2. AutoX.js 실행 → 왼쪽 메뉴에서 **접근성 서비스**, **포그라운드 서비스** 켜기
3. 이 폴더의 `auto_click.js` 파일을 휴대폰으로 옮겨서 AutoX.js 에서 열기
   (또는 AutoX.js 에서 새 파일 만들고 내용 붙여넣기)
4. **▶ 실행** → 바로 한 번 누르고, 이후 60분마다 반복합니다.

파일 맨 위 설정값으로 조절할 수 있습니다:

```js
var APP_NAME = "금한돈";          // 앱 이름
var BUTTON_TEXT = "금 적립하기";   // 누를 버튼
var INTERVAL_MIN = 60;            // 반복 간격(분)
var LOAD_WAIT_SEC = 8;            // 앱 로딩 대기(초)
```

### 패턴 잠금 설정

1. 점 번호는 아래와 같습니다. 내 패턴을 지나가는 순서대로 숫자로 적으세요.
   ```
   1 2 3
   4 5 6
   7 8 9
   ```
   예: ㄱ자(위쪽 가로 → 오른쪽 아래로) = `"1236"`
2. 점 위치 알아내기: 설정 → 휴대전화 정보 → 소프트웨어 정보 → **빌드번호 7번 탭** (개발자 옵션 켜기)
   → 개발자 옵션 → **포인터 위치** 켜기 → 잠금화면에서 1번 점, 9번 점을 각각 눌러 화면 위쪽에 나오는 **X, Y 값**을 적기 → 다시 포인터 위치 끄기
3. 스크립트 위쪽에 입력:
   ```js
   var UNLOCK_PATTERN = "1236";
   var DOT1_X = 250, DOT1_Y = 1500;   // 1번 점 좌표 (예시)
   var DOT9_X = 830, DOT9_Y = 2080;   // 9번 점 좌표 (예시)
   ```
4. 화면을 끄고 스크립트를 실행해 잠금이 풀리는지 확인하세요.

> 🔒 패턴은 **휴대폰 안의 스크립트 파일에만** 적으세요. 채팅이나 다른 곳에 보내지 마세요.

멈추려면 AutoX.js 알림창에서 스크립트를 중지하거나, 앱의 "실행 중인 스크립트"에서 정지하세요.

## 안 될 때

| 증상 | 해결 |
|------|------|
| 몇 시간 뒤 멈춤 | 배터리 최적화 제외 설정 다시 확인 |
| 앱은 열리는데 버튼을 안 누름 | 대기 시간을 8초 → 15초로 늘리기 / 처음에 광고 팝업이 뜨는지 확인 |
| 화면이 안 켜짐 | 화면 잠금을 "없음"으로 변경 |
| 버튼 글자를 못 찾음 | 앱 업데이트로 글자가 바뀌었을 수 있음 → `BUTTON_TEXT` 수정 |

> ⚠️ 자동 클릭은 앱 이용약관에서 금지할 수 있습니다. 적발 시 계정 제재 가능성이 있으니 본인 판단하에 사용하세요.
